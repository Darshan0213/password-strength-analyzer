# Password Strength Analyzer

A simple web-based Password Strength Analyzer built using Python and Flask.

## Features

- Checks password strength
- Detects weak passwords
- Provides security suggestions
- Detects commonly used passwords
- Show/Hide password option
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## How It Works

The application checks a password based on:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Commonly used passwords

It then classifies the password as:

- Weak
- Medium
- Strong
